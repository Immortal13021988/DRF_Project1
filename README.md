# Домашние работы к разделу 8 и 9

## Описание проекта:

1. Создан Django-проект с приложениями users и lms.
2. В приложениях реализованы новые возможности в соответствии с заданием.
3. Добавлена возможность регистрации.
4. Создана группа модераторов с разрешениями.
5. Созданы разрешения для владельцев.
6. Добавлены пагинатор и валидатор. Добавлена модель подписок. 
7. Реализовано тестирование части функционала.
8. Подключен и настроен вывод документации. 
9. Реализована возможность оплаты курсов через  https://stripe.com 
10. Реализован функционал Celery и Celerybeat. Отправка оповещения пользователям об изменениях курсов на которые они подписаны. И дезактивация пользователя, если он не заходил в приложение более 30 дней.
